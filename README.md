# fa-krug Scoop bucket

[Scoop](https://scoop.sh) manifests for [fa-krug](https://github.com/fa-krug) projects.

```powershell
scoop bucket add fa-krug https://github.com/fa-krug/scoop-bucket
scoop install fa-krug/zubi
```

| Manifest | What it is |
| --- | --- |
| `zubi` | The command-line client for [Zubi](https://fa-krug.github.io/zubi/): read and edit the Reminders, calendars and Notes a Mac running Zubi shares. Windows x64 and ARM64. |

The manifests are written by each project's release workflow; changes made here by hand are
overwritten by the next release. Report problems in the project's own repository, for example
[fa-krug/zubi](https://github.com/fa-krug/zubi/issues).
